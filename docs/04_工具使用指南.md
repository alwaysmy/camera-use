# 工具使用指南

## 1. camera_tool.py — CLI 工具

### 1.1 功能列表

| 命令 | 说明 |
|------|------|
| `detect` | 检测所有可用摄像头 |
| `hwinfo` | 获取 Windows 硬件信息 |
| `params` | 查询摄像头参数 |
| `test` | 测试参数可调性 |
| `capture` | 拍照 |
| `record` | 录像 |
| `set` | 设置参数 |
| `preview` | 实时预览 |
| `info` | 综合信息 |
| `list-params` | 列出所有参数名 |
| `auto-exposure` | 设置自动/手动曝光 |

### 1.2 常用命令

```bash
# 检测摄像头
python camera_tool.py detect

# 查看硬件信息
python camera_tool.py hwinfo

# 查看参数
python camera_tool.py params -i 0

# 拍照
python camera_tool.py capture -i 0 -o photo.jpg

# 录像 5 秒
python camera_tool.py record -i 0 -t 5 -o video.mp4

# 设置参数
python camera_tool.py set -i 0 BRIGHTNESS 50

# 实时预览
python camera_tool.py preview -i 0

# 综合信息
python camera_tool.py info -i 0
```

### 1.3 曝光控制命令

```bash
# 设置自动曝光（推荐）
python camera_tool.py auto-exposure auto

# 设置手动曝光
python camera_tool.py auto-exposure manual -2

# 查看当前曝光值
python camera_tool.py auto-exposure auto
# 输出: 当前曝光值: -5 (ISP计算值)
```

### 1.4 参数说明

| 参数 | 范围 | 说明 |
|------|------|------|
| BRIGHTNESS | 0-100 | 亮度 |
| CONTRAST | 0-100 | 对比度 |
| SATURATION | 0-100 | 饱和度 |
| HUE | 0-100 | 色调 |
| GAIN | 0-100 | 增益 |
| EXPOSURE | -10~0 | 曝光值 (Manual模式) |
| SHARPNESS | 0-100 | 锐度 |

### 2.3 操作流程

1. **选择摄像头**：从下拉框选择要使用的摄像头
2. **点击"开始预览"**：启动视频预览
3. **调整参数**：拖动滑块实时调整
4. **切换曝光模式**：Auto/Manual 单选按钮
5. **拍照**：点击"拍照保存"
6. **停止**：点击"停止预览"

### 2.4 曝光模式说明

| 模式 | 说明 |
|------|------|
| Auto | 摄像头自动调整曝光，图像亮度正常 |
| Manual | 手动控制曝光值，EXPOSURE 滑块生效 |

**注意：**
- Auto 模式下，EXPOSURE 滑块无效（由摄像头自动控制）
- 切换到 Manual 后，滑块值会应用到摄像头

## 5. 常见问题

### Q1: 启动时报 "duvc-ctl not installed"

```bash
pip install duvc-ctl
```

### Q2: 摄像头找不到

```bash
# 检查摄像头状态
python camera_tool.py detect

# 检查硬件
python camera_tool.py hwinfo
```

### Q3: 图像仍然很暗

```python
# 确保设置了自动曝光
import duvc_ctl as duvc
cam = duvc.find_camera('HP')
cam.set_exposure(0, 'auto')

# 等待摄像头稳定
import time
time.sleep(2)
```

### Q4: 切换摄像头后曝光模式丢失

每次切换摄像头后需要重新设置曝光模式：

```python
# 在 on_camera_change 中调用
def on_camera_change(self):
    # ... 切换摄像头 ...
    if HAS_DUVC:
        self._open_duvc_camera()
        self._set_auto_exposure()
```

### Q5: PowerShell Disable/Enable 后摄像头失灵

**不要使用 PowerShell 的 Disable/Enable-PnpDevice！**

这会导致驱动栈混乱。正确做法：
1. 等待几分钟让系统自动恢复
2. 或重启电脑
3. 或使用设备管理器禁用/启用
